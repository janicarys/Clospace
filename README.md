# Clospace

Clospace is an Android mobile application designed to help users digitally organize their wardrobe. The application allows users to store garments by category, create outfits, and keep track of what they wear through an interactive calendar interface.

The goal of Clospace is to simplify wardrobe management while encouraging users to make better use of the clothing they already own.

---

## Features

### Authentication
- Splash screen
- Login page
- Sign up page
- Avatar selection during registration

### Closet Management
- Browse clothing by category
  - Tops
  - Bottoms
  - Footwear
  - Accessories
- Horizontal scrolling for garments within each category
- Search bar for quickly finding garments
- Floating Action Button for adding clothing

### Calendar
- Monthly calendar view
- Outfit thumbnails displayed on dates they were worn
- Previous/Next month navigation
- RecyclerView-based calendar implementation

### Settings
- About page
- Support page
- Custom navigation between application pages

## Technologies Used

- Kotlin
- Android Studio
- Material Design 3
- ConstraintLayout
- RecyclerView
- Room Database (currently being integrated)
- ViewBinding (optional if added later)

## Installation

1. Clone the repository

```bash
git clone https://github.com/<username>/Clospace.git
```

2. Open the project in Android Studio.

3. Sync Gradle.

4. Run on an emulator or Android device (Android 6.0+).
